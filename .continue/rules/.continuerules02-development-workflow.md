\# Development Workflow



For every non-trivial task:



1\. Inspect relevant existing files first.

2\. Identify dependencies and affected components.

3\. Make changes using workspace editing tools.

4\. Run the smallest useful test immediately.

5\. Fix errors before continuing.

6\. Periodically run broader tests.

7\. Do not continue building on top of a known broken foundation.



When a change affects multiple files, verify imports and integration between them.



When a command fails twice with the same error, stop repeating it and investigate the cause.



Prefer incremental, verified changes over large speculative rewrites.



Never say "implemented" until the implementation has been tested.



Never say "tested" unless the test actually ran.
